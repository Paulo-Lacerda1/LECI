# Web Site PECI

Website do projeto da licenciatura em Engenharia Computadores e Informática.

## Secções

- **Visão Geral do Projeto** - descrição, resumo técnico e estado atual
- **Equipa** - membros e número mecanográfico
- **Relatórios e Apresentações** - ligações para marcos e entrega final
- **Ligações do Repositório** - código-fonte e documentação
- **Legal e Ética** - licença, créditos de terceiros e privacidade/tratamento de dados
